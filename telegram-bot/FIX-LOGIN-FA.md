# اصلاح ورود Mini App

۱. محتوای `worker.js` را جایگزین کد Worker ربات در Cloudflare کنید و Deploy بزنید. توکن قبلی BOT_TOKEN را نگه دارید.
۲. آدرس `https://YOUR-WORKER.workers.dev/diagnostics` را باز کنید. `upstream: ok` یعنی API اصلی پاسخ می‌دهد. این تست صحت رمز یا حساب را بررسی نمی‌کند.
۳. در تلگرام ربات را باز کنید، `/start` بفرستید و دکمه «داشبورد من» را بزنید؛ از لینک معمولی مرورگر استفاده نکنید.
۴. اگر ورود ناموفق بود، پیام خطا بالای فرم ظاهر می‌شود. فقط متن خطا و آدرس عمومی Worker را ارسال کنید؛ رمز یا توکن را نفرستید.

**توجه:** آدرس API اصلی در ابتدای worker.js تعریف شده و در این بسته همان آدرس نسخه قبلی است. اگر API شما جای دیگری منتشر شده، باید ثابت `API` را اصلاح کنید. تنها تنظیم محرمانه لازم BOT_TOKEN است، اما Worker اصلی سایت و دیتابیس آن باید از قبل فعال باشند.
