# اصلاح دکمه ورود Mini App
در نسخه قبلی، اگر Telegram initData هنگام بارگذاری صفحه موجود نبود، دکمه ورود بی‌صدا غیرفعال می‌شد. اکنون دکمه همیشه قابل کلیک است و علت دقیق مشکل را نشان می‌دهد؛ داده تلگرام نیز هنگام هر درخواست دوباره خوانده می‌شود.
منطق ورود و Service Binding نسخه سالم تغییر نکرده است.

1. از Worker فعلی نسخه پشتیبان بگیرید.
2. worker.js را در menuproai-telegram جایگزین و Deploy کنید. BOT_TOKEN و MENU_API را حفظ کنید.
3. آدرس اصلی Worker را یک‌بار باز کنید تا دکمه منوی تلگرام تنظیم شود.
4. تلگرام را کاملاً ببندید و دوباره باز کنید. از منوی پایین ربات «نبض کسب‌وکار» را بزنید، نه لینک /app در مرورگر.
5. اگر پیام هویت تلگرام ظاهر شد، Mini App هنوز بدون initData باز شده؛ باید از دکمه منوی خود ربات وارد شوید.
6. /diagnostics باید upstream=ok و transport=service_binding باشد.
