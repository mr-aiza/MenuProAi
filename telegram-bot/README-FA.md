# رفع باز شدن Mini App بدون هویت تلگرام
این نسخه علاوه بر منوی دائمی، یک دکمه واقعی web_app در کیبورد چت ربات ایجاد می‌کند تا Telegram اطلاعات initData را هنگام باز کردن Mini App ارسال کند. دو لینک وب در پیام ربات همچنان حفظ شده‌اند.

۱. از Worker فعلی بکاپ بگیرید. worker.js را جایگزین و Deploy کنید. BOT_TOKEN و MENU_API را تغییر ندهید.
۲. یک‌بار آدرس اصلی Worker را باز کنید. این بار نتیجه setWebhook و setChatMenuButton روی صفحه اعلام می‌شود.
۳. در چت خصوصی ربات /start بفرستید. دکمه «🚀 باز کردن نبض کسب‌وکار» در کیبورد پایین چت ظاهر می‌شود؛ از همان دکمه باز کنید.
۴. اگر باز هم initData خالی بود، تلگرام را به‌روز کنید و با دکمه کیبورد ربات امتحان کنید. لینک /app را مستقیم باز نکنید.
۵. صفحه /diagnostics اتصال API را بررسی می‌کند، نه دریافت initData.

توجه: کدهای ورود و API تغییر نکرده‌اند. رمز و توکن خود را برای عیب‌یابی ارسال نکنید.
