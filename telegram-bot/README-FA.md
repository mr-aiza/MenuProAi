# نسخه پایدار نبض کسب‌وکار
این نسخه از Worker نسخه ServiceBinding-Fix که قبلاً کار می‌کرد ساخته شده است. منطق ورود، نشست، اعتبارسنجی تلگرام، Service Binding و مسیرهای API از همان نسخه حفظ شده‌اند. فقط HTML مینی‌اپ، دکمه‌های پیام و نام منوی دائمی تغییر کرده‌اند.

۱. از Cloudflare Worker فعلی نسخه پشتیبان بگیرید.
۲. Service Binding با نام MENU_API به menuproai-api و Secret با نام BOT_TOKEN را حفظ کنید.
۳. محتوای worker.js را جایگزین کنید و Deploy بزنید.
۴. آدرس /diagnostics را بررسی کنید: transport=service_binding و upstream=ok و upstreamStatus=200.
۵. یک‌بار آدرس اصلی Worker را باز کنید تا setWebhook و setChatMenuButton تنظیم شوند. سپس در تلگرام /start بفرستید و از منوی دائمی نبض کسب‌وکار را باز کنید.
۶. آمار بر اساس پاسخ API فعلی است؛ داده‌های ناقص یا قالب‌های متفاوت سفارش ممکن است روی محاسبه اثر بگذارند. روی حساب واقعی آزمایش کنید.

اگر /diagnostics سالم بود ولی ورود خطا داشت، متن خطا را ارسال کنید؛ رمز یا توکن را نفرستید.
