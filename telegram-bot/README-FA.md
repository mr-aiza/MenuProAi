# ربات مرکزی MenuProAI + Telegram Mini App

این نسخه با بک‌اند موجود همین ZIP سازگار است و **تنها متغیر لازم در Cloudflare Worker جدید، `BOT_TOKEN` است**. آدرس API موجود در کد روی `https://menuproai-api.bytelab.workers.dev` تنظیم شده است. اگر آدرس API عوض شود باید ثابت `API` را در ابتدای Worker تغییر دهید.

## نصب با Cloudflare (بدون KV یا D1 جدید)

1. در تلگرام از `@BotFather` ربات بسازید و توکن را نزد خود نگه دارید. توکن را در چت یا مخزن GitHub نگذارید.
2. در Cloudflare → Workers & Pages → Create Worker، یک Worker جدید بسازید (مثلاً `menuproai-telegram`). کد کامل فایل `telegram-bot/worker.js` را در ویرایشگر جای‌گذاری و Deploy کنید. **فایل worker.template.js را نصب نکنید**.
3. Settings → Variables and Secrets → Add → نوع **Secret**، نام `BOT_TOKEN`، مقدار توکن BotFather. ذخیره و Deploy کنید. اگر نام متغیر را اشتباه بزنید سرویس 503 می‌دهد.
4. آدرس عمومی Worker مانند `https://menuproai-telegram.YOUR-SUBDOMAIN.workers.dev/` را **یک‌بار در مرورگر باز کنید**. بازدید از صفحه اصلی به‌طور خودکار webhook، منوی تلگرام و دستورات ربات را تنظیم می‌کند؛ ۵ تا ۱۰ ثانیه صبر کنید. برای بررسی webhook در صورت نیاز از BotFather یا Telegram getWebhookInfo استفاده کنید. اگر آدرس Worker تغییر کرد، دوباره صفحه اصلی را باز کنید.
5. به ربات در تلگرام `/start` بفرستید، «داشبورد من» را باز کنید، با همان شماره و رمز مالک سایت وارد شوید. فقط حسابی که در API اصلی منو ساخته باشد، اطلاعات داشبورد دارد.

## قابلیت‌ها

- یک ربات واحد برای همه مالکان؛ احراز هویت واقعی با API فعلی؛ هر مالک فقط منوی متعلق به نشست خودش را می‌بیند.
- دکمه‌های تلگرام برای داشبورد، سفارش‌ها، رزروها، منو و وب‌سایت؛ Mini App با نمای خانه، محصولات، سفارش‌ها، رزروها و تغییر وضعیت.
- رمز در چت تلگرام ارسال نمی‌شود. داده `initData` تلگرام در Worker با HMAC بررسی می‌شود. نشست API در کوکی رمزگذاری‌شده HttpOnly نگهداری می‌شود و به شناسه تلگرام متصل است. خروج، نشست API را باطل می‌کند.
- **بدون نیاز به Worker KV یا دیتابیس جدید**، زیرا سفارش‌ها، رزروها و اطلاعات مالک در بک‌اند فعلی MenuProAI هستند.

## محدودیت‌های مهم

- برای **اعلان خودکار سفارش و رزرو در تلگرام**، لازم است شناسه chat هر مالک به‌صورت پایدار ذخیره شود و بک‌اند هنگام رویداد به ربات اطلاع دهد؛ این ویژگی در نسخه بدون KV/D1 فعال نیست. در حال حاضر مالک می‌تواند از دکمه‌ها وضعیت‌ها را مشاهده و به‌روزرسانی کند.
- دکمه‌های تلگرام، Mini App را باز می‌کنند؛ نمایش داده‌های شخصی مستقیماً در متن چت بدون ذخیره اتصال حساب/شناسه چت ارائه نشده است.
- ورود به Mini App فقط از داخل تلگرام ممکن است. مرورگر عادی `initData` معتبر ندارد.
- اگر بک‌اند اصلی هنوز روی Cloudflare نصب نشده یا متغیر `MENU_KV` آن وصل نیست، ورود و داده‌ها کار نمی‌کنند. **این Worker جایگزین Worker اصلی سایت نیست** و Worker اصلی را تغییر نمی‌دهد.
- گزارش درآمد در Mini App بر اساس سفارش‌های برگشتی API محاسبه می‌شود، نه تسویه بانکی. برای آمار کامل از داشبورد سایت استفاده کنید.
- اولین درخواست صفحه اصلی webhook را ثبت می‌کند. برای تأیید عملی، `/start` را امتحان کنید؛ صفحه `/health` صرفاً زنده بودن Worker را نشان می‌دهد، نه موفقیت اتصال تلگرام.
